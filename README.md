# ZarCoin (ZAR)

**ارز با قیمت ثابت نصف دلار آمریکا**

## ویژگی‌ها
- قیمت هدف: همیشه **۰.۵ دلار**
- نمایش لایو به تومان و ریال
- به‌روزرسانی خودکار
- قرارداد توکن ERC-20 آماده

## لینک‌ها
- ریپو: https://github.com/nimarahimloo/zarcoin
- صفحه قیمت: فایل `index.html` (یا بعد از فعال‌سازی GitHub Pages: https://nimarahimloo.github.io/zarcoin/)
- قرارداد توکن: [`contracts/ZarCoin.sol`](contracts/ZarCoin.sol)

## وضعیت فعلی

| بخش | وضعیت |
|------|--------|
| صفحه قیمت لایو | ✅ آماده |
| قرارداد ERC-20 | ✅ آماده |
| قیمت هدف ۰.۵ دلار | ✅ |
| اتصال به API نرخ آزاد ایران | ⏳ مرحله بعد |

## نحوه استفاده از صفحه قیمت
1. فایل `index.html` را دانلود یا در مرورگر باز کنید.
2. قیمت همیشه نصف نرخ دلار (به تومان/ریال) نمایش داده می‌شود.

## نحوه استفاده از توکن
قرارداد `ZarCoin.sol` یک ERC-20 ساده‌است. می‌توانید آن را روی شبکه‌های تست (Sepolia, BSC Testnet و ...) یا مین‌نت دیپلوی کنید.

برای دیپلوی با Remix:
1. به https://remix.ethereum.org بروید
2. فایل را کپی کنید
3. Compile کنید
4. Deploy با مقدار initialSupply دلخواه (مثلاً ۱۰۰۰۰۰۰۰۰)

## مرحله بعدی پیشنهادی
- فعال‌سازی GitHub Pages برای آنلاین شدن صفحه قیمت
- اتصال واقعی به API نرخ دلار آزاد (bonbast / tgju) از طریق یک بک‌اند ساده
- دیپلوی توکن روی تست‌نت و اضافه کردن لینک قرارداد
