# ZarCoin (ZAR)

**ارز با قیمت ثابت نصف دلار آمریکا**

## ویژگی‌ها
- قیمت هدف: همیشه **۰.۵ دلار**
- نمایش لایو به تومان و ریال
- به‌روزرسانی خودکار
- قرارداد توکن ERC-20 آماده
- راهنمای کامل دیپلوی روی تست‌نت
